# Logo

Vector traces of Raf Geerts' own logo (`Logo.png` on betontrappenraf.be): RAF GEERTS over BETONTRAPPEN in the logo's rounded heavy lettering. Five files; pick by ground, never recolour.

- `rg-logo.svg`: RAF GEERTS in black #000000, BETONTRAPPEN in red-500 #E83E4D. White, concrete-50 and light photos.
- `rg-logo-on-dark.svg`: white #FFFFFF and red-500. Dark theme, concrete-950, dark photos.
- `rg-logo-on-red.svg`: black and white. The Red theme ground, as on the van.
- `rg-logo-mono-black.svg`: all black. Print, stamps, forms.
- `rg-logo-mono-white.svg`: all white. Workwear, signage on black, photo overlays.

Minimum height 32px. Clear space: the height of the E in BETONTRAPPEN on every side. Shown through `<img>`, so the inks are fixed in the files.
