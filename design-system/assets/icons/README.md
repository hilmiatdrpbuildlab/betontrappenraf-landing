# Icons

46 Lucide icons (lucide-static 1.49.0, ISC licence), 24×24 grid, stroke 2, `stroke="currentColor"`. The build inlines them as SVG with square caps and mitred joins (`stroke-linecap="square" stroke-linejoin="miter"`) so they take the text colour and match the square system. Shown through an `<img>` tag they render black with round caps. Default size 20px (`.rg-icon`).

`facebook.svg` is the Simple Icons mark (CC0): filled, single ink, inlined with `fill="currentColor"`. Footer and contact block only.

Fixed roles: `arrow-right` in buttons and text links, `arrow-up-right` on project cards, `phone`, `mail`, `map-pin` for contact, `ruler`, `hammer`, `layers`, `check` for the Werkwijze steps, `info`, `circle-check`, `triangle-alert`, `circle-x` for status, `plus` and `minus` in the FAQ, `chevron-down` in selects, `loader-circle` for loading, the rest for the CMS.
