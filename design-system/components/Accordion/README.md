# Accordion

Question-and-answer rows on native `details`/`summary`, used for the FAQ on the website and for collapsible groups (SEO settings) in the CMS.

## Use
- `.rg-accordion` > `details.rg-accordion__item` > `summary` (the question + `span.rg-accordion__toggle` holding the `plus` and `minus` icons with classes `rg-icon--plus` and `rg-icon--minus`) + `.rg-accordion__answer`.
- No script needed: the browser handles open, close and keyboard. Open the first item by default with `open`.
- The list opens with a 1px ink rule; the open toggle fills with ink.
- Questions in the reader's words, ending in a question mark. Answers in two or three sentences, `u` form.

## Content
The answers in the preview describe cast-in-place work in general terms. Have Raf confirm them, and never add lead times, guarantees or prices he has not given.
