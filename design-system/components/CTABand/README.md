# CTABand

The red call-to-action band, carried over from the current site: black condensed type on `red-500`, the phone number set large and one black button.

## Use
- `section.rg-cta[data-theme="red"]` > `.rg-container` > `.rg-cta__inner` with `.rg-cta__copy` (eyebrow, `t-h1` or `t-h2`, one sentence) and `.rg-cta__actions` (`a.rg-cta__phone`, one `rg-btn--lg`).
- In the Red theme `accent` is black and `on-accent` white, so the default button needs no extra class.
- One Red band per page, near the end, before the footer. Put a Light section between it and any Dark section.
- The headline can be the site's own **Betontrappen ter plaatse bekist**.

## Avoid
- Forms, cards, photos or badges in a Red band.
- White text on the red ground (4.0:1).
- Red buttons inside Red.
